# مستودع محتوى مدونة ZERO 2 ONE

**المقالات والصور فقط.** لا منطق بناء، ولا قوالب، ولا أسرار ذات قيمة.

هذا الفصل مقصود: اختراق حساب الكاتب لا يمنح المهاجم خط بناء يعدّله. أقصى ضرر
ممكن مقال سيّئ وتشغيل بناء عبثي — وكلاهما يُتراجع عنه بدقيقة.

## بنية المقال — حزمة صفحة

```
content/blog/<slug>/
    index.en.md      ← النسخة الإنجليزية
    index.ar.md      ← النسخة العربية (اختيارية)
    cover.webp       ← صورة المشاركة
    *.webp           ← بقية صور المقال
```

**الصور داخل مجلد المقال حصراً**، لا مجلد صور عام. حُذف المقال، حُذف مجلده معه —
فلا تبقى صور يتيمة، ولا حاجة لحذف آلي قد يمحو صورة حية بالخطأ.

## الروابط

| | الإنجليزية | العربية |
|---|---|---|
| المقال | `/blog/{slug}/` | `/blog/ar/{slug}/` |

**الرابط بعد النشر لا يتغيّر.** تغييره إجراء استثنائي يتطلب إعادة توجيه 301،
وإلا ضاع ترتيب المقال في نتائج البحث.

## الحقول الإلزامية

المصدر الواحد وقيوده الكاملة:
[`controls/schema.json`](https://github.com/zeroone01z21-alt/blog-build/blob/main/controls/schema.json)

| الحقل | القيد |
|---|---|
| `title` | 10–70 محرفاً |
| `description` | 50–160 محرفاً — هذا ما يظهر في نتائج البحث |
| `slug` | حروف إنجليزية صغيرة وأرقام وشرطات |
| `draft` | `true` افتراضياً — لا يُنشر شيء بالخطأ |
| `categories` | تصنيف واحد على الأقل |
| `featured_image` + `featured_image_alt` | إلزاميان — البناء يفشل بدونهما |

## للكاتب

لن تحتاج فتح هذا المستودع إطلاقاً. اكتب من اللوحة، والباقي آلي.
دليلك المبسّط سيصلك عند اكتمال الإعداد.

## ماذا يحدث عند الحفظ

```
تحفظ في اللوحة  →  يُكتب الملف هنا  →  إشارة إلى blog-build
                                            ↓
                                    تحقّق + بناء + فحوص جودة
                                            ↓
                                    نشر على zero2one.sa/blog/
```

الفحوص تمنع النشر الناقص: عنوان مفقود، وصف قصير، صورة بلا نص بديل، صورة أكبر
من الحد. **الرسالة تصلك بالعربية وفيها ما الخطأ وأين وكيف تصلحه.**
